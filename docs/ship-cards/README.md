# Printable ship cards

This set contains all nine current ship classes plus three quick-reference cards. The generator reads statistics and weapon loadouts directly from `GameDefinition`; the illustrations are the same tactical artwork used by the browser game.

Build the US-Letter PDF with:

```sh
make
```

The build produces `build/the-shattered-reach-ship-cards.pdf` and publishes a copy to `public/the-shattered-reach-ship-cards.pdf` for download from the prototype.

Print at **Actual Size / 100%**, single-sided, on Letter paper. Each card is 4 × 5 inches; four cards fit on each sheet. Cut on the outer card borders. Card sleeves or lamination make the tracks reusable with dry-erase markers.
